# Responsive Login Form with Data Table

A React + TypeScript application built as a front-end coding assignment.

---

## Tech Stack

* React
* TypeScript
* Vite
* React Router DOM
* Fetch API
* Local Storage API
* CSS

---

## Getting Started

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```
